NAME
     MPI_File_iread_at - Performs a nonblocking read using an explict offset

SYNOPSIS
     C:

	  #include "mpi.h"

	  int MPI_File_iread_at(MPI_File fh, MPI_Offset offset,
	  void *buf, int count, MPI_Datatype datatype,
	  MPI_Request *request)


     Fortran:

	  INCLUDE "mpif.h" (or USE MPI)

	  <type> BUF(*)
	  INTEGER fh, count, datatype, request, ierror
	  INTEGER(KIND=MPI_OFSET_KIND) offset

	  CALL MPI_FILE_IREAD_AT(fh, offset, buf, count,
	  datatype, request, ierror)


DESCRIPTION
     MPI_File_iread_at is a nonblocking version of the MPI_File_read_at
     interface.

     MPI_File_iread_at accepts the following arguments:

     fh        Specifies the file handle (handle)

     offset    Specifies the file offset (nonnegative integer)

     count     Specifies the number of elements in the buffer (nonnegative
	       integer)

     datatype  Specifies the datatype of each buffer element (handle)

     buf       Returns the initial address of the buffer (choice)

     request   Returns the request object (handle)

     ierror    Specifies the return code value for successful completion,
	       which is in MPI_SUCCESS.  MPI_SUCCESS is defined in the mpif.h
	       file.

   Notes for Fortran
     All MPI objects (for example, MPI_Datatype, MPI_Comm, MPI_File) are of
     type INTEGER.
